# ESP8266 Smart Plant Care

ESP8266 ile gelistirilen akilli bitki
bakim ve izleme projesi.

- DHT11 ile sicaklik ve hava nemi olcumu.
- Toprak nem sensorunden analog veri okuma.
- Wi-Fi baglantisi ve HTTP web sunucusu.
- `/api/sensors` ile JSON sensor verileri.
- Toprak nem testi ve olcum kayitlari.

**Durum:** Sensor okuma ve Wi-Fi haberlesmesi
test edildi. Otomatik sulama gelistirme asamasinda.

Not: Toprak nemi henuz kalibre edilmemistir.
